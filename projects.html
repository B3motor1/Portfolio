AI Parking Space Detection System

Feb to Mar 2026
PythonYOLOv8OpenCV Computer VisionWeb Dashboard

Project Description

OpenPark is a hackathon project built to eliminate parking headaches by detecting available spots in real time using aerial camera footage. It runs a YOLOv8 computer vision model trained on over 10,000 images to identify empty versus occupied spots with high accuracy. The data feeds into a live web dashboard that displays parking lot layouts, highlighting open spots in green and taken ones in red so drivers can quickly find a place to park.

Project Description

Micromouse is an autonomous maze-solving robot that uses IR sensors to detect any walls ahead of it. The goal is to blindly finish a maze as quickly as possible with the best algorithm. Very old IEEE tradition. The way I designed this was to make my main body a PCB, which I designed in EasyEDA. It’s a team project with my close friends here at UH.

DIY Lithium-Ion Power Bank

Project Description

I found a few dead vapes on campus and broke them apart to extract their single-cell lithium batteries, wiring three in parallel for more capacity. To charge my phone, I wired the pack to a $2 134N3P Micro USB board, which handles both battery management and boosting the output from 3.7V to 5V.

ESP32-CAM CCTV Workshop

April 2026
ESP32-CAMArduinoPan/Tilt Servos Wi-Fi Streaming3D PrintingTeaching

Project Description

When I was a Project Chair for IEEE@UH, I hosted a beginner workshop on building a cheap, web-controlled CCTV camera using an ESP32-CAM and a pair of servos for pan/tilt control. It’s a fun intro to hardware and IoT that covers wiring, 3D printing custom mounts, and controlling a live stream over Wi-Fi. I put together a GitHub repo with the Arduino code, STL files, and step-by-step tutorial slides so anyone can follow along and build one.
