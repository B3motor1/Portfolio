AI Parking Space Detection System

Feb – Mar 2026
Python YOLOv8 OpenCV Computer Vision Web Dashboard

OpenPark is a hackathon project built to eliminate parking headaches by detecting available spots in real time using aerial camera footage. It runs a YOLOv8 computer vision model trained on over 10,000 images to identify empty versus occupied spots with high accuracy. The data feeds into a live web dashboard that displays parking lot layouts, highlighting open spots in green and taken ones in red so drivers can quickly find a place to park.

EasyEDA Custom PCB ESP32 C++ IR Sensors Flood-Fill

Micromouse is an autonomous maze-solving robot that uses IR sensors to detect any walls ahead of it. The goal is to blindly finish a maze as quickly as possible with the best algorithm. I found a few dead vapes on campus and broke them apart to extract their single-cell lithium batteries, wiring three in parallel for more capacity. To charge my phone, I wired the pack to a $2 134N3P Micro USB board, which handles both battery management and boosting the output from 3.7V to 5V.
